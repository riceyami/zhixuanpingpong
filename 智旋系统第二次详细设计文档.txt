本文档为第二个详细设计文档，聚焦系统内算法复杂度最高、业务链路最长的两大核心场景：视频 AI 乒乓球分析算法、LBS 约球智能匹配业务。因单函数代码行数限制，将完整逻辑拆分为多个子函数 / 方法，明确各函数流程、入出参、调用关系，确保与概要设计、最终代码完全对齐。

2 核心复杂业务总览
2.1 业务边界
AI 分析业务：视频上传完成 → 帧提取 → 球检测 → 轨迹追踪 → 球速 / 落点计算 → 结果入库
LBS 匹配业务：用户定位 → 模糊化 → 距离计算 → 球友 / 球馆筛选 → 约池匹配 → 排序展示
2.2 设计约束
单函数代码行数 ≤ 80 行
函数单一职责：一个函数只完成一个子逻辑
调用关系清晰：同步 / 异步调用明确，无循环依赖
算法可复用：提取公共工具函数，跨模块调用

3 视频 AI 分析算法详细设计（高复杂度算法）
3.1 算法总目标
从用户上传的乒乓球训练视频中，自动识别乒乓球、追踪运动轨迹、计算实时球速、统计落点分布，输出标准化分析结果。
3.2 整体函数拆分与调用关系
3.3 子函数详细设计
3.3.1 analyzeVideo（总入口函数）
功能：调度全流程 AI 分析，处理异常与状态更新
入参：videoId、fileUrl、duration
出参：resultId、分析状态、错误信息
流程：
校验视频文件有效性
调用预处理→检测→追踪→计算→统计
异常捕获，更新任务状态
入库结果数据
3.3.2 videoPreprocess（视频预处理）
功能：格式转换、去重帧、提取有效帧
入参：fileUrl、duration
出参：帧列表、帧率 fps、总帧数
子函数：
getVideoFps ()：获取视频帧率
extractValidFrames ()：按间隔抽帧，减少计算量
3.3.3 detectTableTennis（乒乓球目标检测）
功能：在单帧中定位乒乓球坐标
入参：单帧图像
出参：球坐标 (x,y)、置信度
子函数：
colorFilter ()：橙色 / 白色球颜色空间过滤
contourMatch ()：轮廓匹配，过滤干扰目标
3.3.4 trackBallTrajectory（轨迹追踪）
功能：关联多帧球坐标，生成连续轨迹
入参：所有帧的球坐标列表
出参：轨迹点列表（含时间戳）
子函数：
matchTrajectoryPoint ()：帧间坐标匹配
smoothTrajectory ()：卡尔曼滤波，平滑轨迹
3.3.5 calculateBallSpeed（球速计算）
功能：根据轨迹与时间戳计算实时 / 平均球速
入参：轨迹点列表、fps
出参：maxSpeed、avgSpeed、速度序列
算法：距离 / 时间 → 转换为 km/h
3.3.6 statisticsLandingPoints（落点统计）
功能：识别球台落点，生成热力图数据
入参：轨迹点、球台坐标范围
出参：落点坐标列表、落点分区统计
3.3.7 generateAnalyzeResult（结果聚合）
功能：聚合所有算法数据，生成标准结果
入参：轨迹、速度、落点、击球次数
出参：AnalyzeResult 对象（存入 MongoDB）
3.4 算法关键约束
检测置信度阈值 ≥ 0.85
轨迹平滑窗口 = 5 帧
最小球速阈值 ≥ 10km/h（过滤误检）
单视频分析时长 ≤ 60 秒

4 LBS 约球智能匹配业务详细设计（复杂业务流程）
4.1 业务总目标
基于用户位置，隐私保护模糊定位，精准计算距离，智能筛选附近球友 / 球馆，按优先级匹配约球，提升线下约球成功率。
4.2 整体函数拆分与调用关系
4.3 子函数详细设计
4.3.1 matchNearbyBallFriends（总入口函数）
功能：调度约球匹配全流程，处理定位权限与参数
入参：userId、searchRadius、matchType（球友 / 球馆 / 约球）
出参：匹配列表、总数、距离范围
4.3.2 getUserRealLocation（获取真实定位）
功能：获取用户 GPS / 手动输入位置
入参：授权状态
出参：经纬度 (lng, lat)、城市
子函数：getHtml5Location ()：浏览器定位获取
4.3.3 fuzzyLocationProcess（定位模糊化）
功能：坐标偏移，保护用户隐私
入参：真实 lng、lat
出参：模糊 lng、lat（偏移 50-100 米）
算法：随机偏移 + 范围约束
4.3.4 calcDistanceBetweenPoints（距离计算）
功能：计算两点间球面距离（米）
入参：坐标 A、坐标 B
出参：距离（米）
子函数：haversineFormula ()：哈弗辛球面公式实现
4.3.5 filterNearbyTargets（筛选目标）
功能：按半径、时间、人数过滤有效目标
入参：模糊定位、半径、筛选条件
出参：候选球友 / 球馆 / 约球列表
4.3.6 calculateMatchScore（匹配分计算）
功能：生成匹配优先级分数
入参：距离、时间匹配度、人数余量、用户活跃度
出参：matchScore（0-100）
4.3.7 sortMatchResult（结果排序）
功能：按匹配分→距离→时间排序
入参：候选列表
出参：排序后的最终匹配列表
4.3.8 returnMatchList（结果封装）
功能：封装列表数据，返回前端渲染
入参：排序后列表
出参：标准化分页数据
4.4 业务关键规则
定位偏移：50-100 米随机
搜索半径：500 米 - 5 公里
匹配权重：距离 40%+ 时间 30%+ 人数 20%+ 活跃度 10%
缓存：附近数据缓存 10 分钟，减少地图 API 调用

5 函数调用时序图（核心流程）
5.1 AI 分析时序
前端提交分析 → analyzeVideo ()
视频预处理 → 帧提取
逐帧检测球 → 轨迹追踪
计算速度 / 落点 → 生成结果
回调前端 → 数据渲染
5.2 LBS 匹配时序
用户进入约球页 → 获取定位
模糊化处理 → 计算距离
筛选候选目标 → 算分排序
返回列表 → 地图 / 列表展示

7.2 容错机制

8 其他设计
8.1 算法性能优化
AI 分析：GPU 加速、帧降采样、批量处理
LBS 匹配：Redis 缓存附近数据、预计算距离
函数：懒加载、异步执行、避免重复计算
8.2 数据一致性
AI 结果：原子入库，确保轨迹 / 速度 / 落点同生命周期
LBS 匹配：定位变更实时刷新，缓存及时失效
